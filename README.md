## Setup Instructions

### 1. Clone the repository

Copy the repository URL from GitHub and use VS Code's **Git: Clone** command to clone it.

### 2. Open the project

Open the cloned `github-practice` folder in VS Code.

### 3. Make changes

Open `README.md` or another project file, edit the content, and save with `Ctrl + S`.

### 4. Save changes to GitHub

Use VS Code Source Control to stage your changes, enter a commit message, commit, and push your branch to GitHub.

### 5. Submit your changes

Open a pull request on GitHub to propose merging your branch into `main`.
